ШАГ 3 ИЗ 6

Создайте администратора

Минимум 14 символов. Сохраняется только Argon2id-хеш.

Код создаётся в Node Manager и действует ограниченное время. Для локального HTTPS передайте CA из System Management главного ПК. TLS не отключается.

Служба продолжает работать после закрытия окна. Steam и CS2 требуют активного пользовательского сеанса Windows.

Можно начинать работу

SYSTEM MANAGEMENT

Управление системой

Состояние локальных компонентов, резервные копии и подключения.

Обслуживание

Выход из приложения через меню или трей корректно останавливает его локальные процессы.

Обновления

Обновления проверяются только через настроенный издателем подписанный канал HTTPS.

Приложение не обходит Windows SmartScreen. Неподписанные Windows-установщики могут требовать дополнительного подтверждения.

Разрешённые локальные приложения

Выберите официальные steam.exe и cs2.exe на этом компьютере. Произвольные программы и удалённые аргументы запуска не разрешаются. В Steam нужно войти вручную.

Telegram-уведомления

Состояние ещё не запрошено.

Пустой токен отключает Telegram. Секрет сохраняется защищённым Windows DPAPI; существующий токен не возвращается в интерфейс.

Подключение других компьютеров

Явно включите HTTPS на конкретном адресе своей сети. Брандмауэр не изменяется автоматически.

Передайте сертификат по доверенному каналу вместе с одноразовым кодом из Nodes. Сертификат не содержит приватный ключ.

Фоновая служба Windows

Служба работает независимо от окна. Управление требует согласия администратора Windows. После удаления защищённые данные подключения остаются в ProgramData.

Диагностика и ошибки

Нет записей.
Пароли Steam не хранятся. Произвольные удалённые команды не выполняются.
