# CS2 Farm Manager — Windows Desktop

Существующая панель управления Steam/CS2 дополнена настольной оболочкой Electron, графическим мастером и автоматическим supervisor. В автономном режиме используются встроенные Python/Node.js, SQLite WAL и сохраняемая очередь; устанавливать Python, Node.js, PostgreSQL, Redis или Docker пользователю не требуется.

**Protection Engine 2.0 / приложение 0.4.0:** [руководство](docs/FARM-PROTECTION-ENGINE-2-RU.md). Независимый Safety Engine, локальная защита узла при потере связи, Account Health с источниками и временем, проверка целостности, сохранение блокировки после рестарта, возврат после проверки администратором и ACK агента. Сохранены официальные сведения Steam, Compliance Engine, аудит и Telegram-outbox. Неизвестные сведения не объявляются блокировками; прогноз VAC отсутствует.

**Состояние поставки 0.4.0:** настоящие `CS2-Farm-Manager-Setup.exe` и `CS2-Farm-Agent-Setup.exe` прошли [полный Windows CI](https://github.com/boyyhbm/Farm/actions/runs/41934955027): сборка, установка, автоматический запуск, сохранение данных, две службы агента, задания, изоляция узла, восстановление и удаление. [Отчёт с результатами и границами проверки](docs/FARM-PROTECTION-ENGINE-2-VALIDATION-RU.md), [проверенные EXE и отчёты в черновике GitHub](https://github.com/boyyhbm/Farm/releases), [контрольные суммы](docs/windows-native-verification.json). Среда — Windows Server 2022; чистая Windows 11, настоящая перезагрузка и два физических ПК остаются в [чек-листе](docs/WINDOWS-LOCAL-CHECKLIST-RU.md). EXE **не подписаны**. ZIP с исходниками не является установщиком.

## Пользовательский запуск после выпуска установщиков

1. Скачайте **CS2-Farm-Manager-Setup.exe**, откройте графический мастер и установите программу.
2. Запустите ярлык **CS2 Farm Manager** на рабочем столе или в меню «Пуск».
3. Выберите «Главный компьютер», создайте администратора и завершите настройку. Программа сама создаст БД и запустит Backend, локальную очередь и Dashboard.
4. Войдите в панель и добавьте Steam-аккаунты. Авторизация в официальном Steam выполняется вручную на соответствующем ПК.
5. Для дополнительного ПК скачайте **CS2-Farm-Agent-Setup.exe** из Nodes и установите его обычным мастером.
6. В System Management главного приложения явно включите HTTPS для выбранного сетевого интерфейса. Передайте агенту адрес сервера, публичный CA и одноразовый код из Nodes. Если Windows запрашивает разрешение сети, разрешайте только свою доверенную частную сеть.
7. На агенте выберите фоновую службу и подтвердите UAC либо используйте интерактивный режим. При необходимости выберите установленные `steam.exe` и `cs2.exe` через графический выбор файла. Дождитесь реальной телеметрии в Node Manager.

Никаких команд или ручного редактирования конфигурации в этом пользовательском процессе нет. Подробности: [руководство Windows](docs/windows-desktop-user-guide.md).

## Desktop-возможности

- Собственные окна, трей, уведомления Windows, сворачивание в трей и управляемый выход.
- Три режима: главный компьютер, агент и подключение к существующему HTTPS-серверу.
- Автоматический запуск локальных компонентов, реальные healthchecks, идентификация собственных процессов и ограниченное восстановление.
- System Management: состояние компонентов, диагностика, перезапуск, backup/restore, HTTPS, Telegram и пути приложений агента.
- Автозапуск Manager после входа пользователя. Agent поддерживает фоновую службу LocalSystem, установленную через графический UAC-мастер, и прежний интерактивный режим. Steam/CS2 требуют активного пользовательского сеанса.
- Подписанные обновления проверяются только при настроенном издателем HTTPS-канале. Пока канал не опубликован, интерфейс сообщает о недоступности проверки.

Брандмауэр, доверенные сертификаты ОС, SmartScreen и антивирусные исключения автоматически не изменяются. Неподписанный EXE может вызвать предупреждение Windows. Пароли Steam/Steam Guard не собираются; автоматизация официальных матчей и получения наград отсутствует.

## Существующие функции сохранены

Dashboard, Accounts, Nodes, Sessions, Scheduler, Inventory, Weekly Drops, Market, Analytics, Audit Logs, Telegram, публичное API и изолированный Gameplay Test Engine используют существующую серверную логику. PostgreSQL + Redis/Celery остаются вариантом масштабируемого сервера; автономный SQLite предназначен для одного небольшого локального развёртывания.
