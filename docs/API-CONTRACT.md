# Implementation contract
Base /api/v1, same-origin via reverse proxy. JSON, UTC ISO8601. Auth: opaque HttpOnly cookie `farm_session`; login POST /auth/login {username,password}, GET /auth/me -> {id,username,role,csrf_token}; mutations require X-CSRF-Token from me/login. POST /auth/logout. Roles admin/operator/viewer. Initial admin via environment.
Lists return {items:[],total:int,page:int,page_size:int}; query page=1,page_size=50,q=... . Errors {detail:string}.
GET /dashboard/overview returns {accounts,active_accounts,nodes_online,nodes_offline,running_sessions,confirmed_drops,inventory_value,errors_24h,cpu_percent,ram_percent,gpu_percent,job_counts:Record<string,number>,value_history:[{date,value}]} (unavailable metrics null).
/accounts CRUD: {id,steam_id,nickname,profile_url,prime_status:'unknown'|'confirmed'|'unconfirmed',inventory_visibility,assigned_node_id,tags:string[],notes,archived,estimated_value,last_sync,last_drop,created_at}; create {steam_id,notes?,tags?,assigned_node_id?,prime_status?}. PATCH same. DELETE archive if history exists. POST /accounts/import raw text/csv body (header steam_id,notes,tags), GET /accounts/export CSV. POST /accounts/bulk {ids,changes}.
/nodes list: {id,hostname,os_version,hardware:object,agent_version,status,last_heartbeat,last_error,metrics:object,revoked}; GET /nodes/{id}/metrics list. POST /nodes/enrollment-tokens -> {token,expires_at}. POST /nodes/{id}/revoke, POST /nodes/{id}/restart. Enroll agent POST /nodes/enroll {token,hostname,os_version,hardware,agent_version} -> {node_id,credential}.
/jobs list {id,account_id,node_id,kind,status,priority,payload,attempts,max_attempts,timeout_seconds,error,created_at,scheduled_at}; POST {account_id?,node_id?,kind:'test'|'steam'|'cs2',priority?:0,payload?:{duration_seconds:60,seed:1},timeout_seconds?:300,max_attempts?:3,scheduled_at?:ISO} with Idempotency-Key UUID. /jobs/{id}/cancel, /jobs/{id}/retry POST. POST /control/emergency-stop, /control/pause, /control/resume. GET /control -> {paused}. Nodes capacity 1 for Steam/CS2, test capacity configurable.
/sessions list {id,job_id,account_id,node_id,status,pid,exit_code,error,started_at,ended_at,resource_usage}; POST /sessions/{id}/stop.
/schedules CRUD {id,name,enabled,interval_seconds,next_run,job_template}; POST fields name,interval_seconds,next_run,job_template (job create body). No arbitrary cron.
/inventory/{account_id} GET -> {items,snapshots,changes}; POST .../sync -> {task_id,status:'queued'}; GET /inventory/export?account_id=... CSV. GET /market list of prices.
/drops list {id,account_id,period_id,status,item_name,value,currency,source,confirmed_at}; POST /drops/confirm {account_id,period_id,item_name,value,currency:'USD',source}; GET /drops/periods list; POST /drops/periods {starts_at,ends_at,source} requires verified source, no invented reset. POST /drops {account_id,period_id,status,item_name?,value?,source?}.
/analytics/overview {expenses,revenue,fees,realized_profit,inventory_value,unrealized_value,roi,payback_months,series:[{date,expenses,revenue}]}; GET /expenses, /revenues paginated, POST /expenses {category,amount,currency:'USD',description,occurred_at}, POST /revenues {amount,fees,currency:'USD',description,occurred_at}; base currency USD, no FX implied. GET /analytics/export CSV.
/logs paginated audit {id,actor,action,target,details,created_at}. /notifications list. /settings GET {telegram_configured,base_currency:'USD',weekly_period_policy,...}; /users GET/POST admin users {username,password,role}.
Live dashboard WS /ws/live uses same session cookie and allowed Origin; events are invalidation notifications {type:'refresh'} (Redis pubsub) or snapshot refresh each 10sec. UI refetch queries.
Agent WS /ws/agent header Authorization Bearer credential, validates each heartbeat. Receives {type:'command',command_id,operation:'start'|'stop'|'restart_agent',session_id,kind,payload,deadline}. Replies {type:'ack',command_id,status:'RUNNING'|'STOPPED'|'FAILED',pid?,exit_code?,error?,resource_usage?}. Heartbeat {type:'heartbeat',metrics:{cpu_percent,ram_percent,gpu_percent,disk_free_gb,...},processes:[],hardware?}. Replays identical command IDs return previous ack. Agent never accepts remote executable paths or arbitrary shell arguments. Commands persisted server-side and delivered on each heartbeat until ack.
