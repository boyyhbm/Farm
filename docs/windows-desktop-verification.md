## Что исправлено по результатам реальных прогонов

Исправлены unnamed Windows Job Object, тестовая фикстура PID, путь импорта дочернего движка, поиск `npm.cmd`, кавычки и пути native NSIS, исключённый упаковщиком `node_modules` Next, наследование ACL файлов службы, ограничение завершения открытых WSS, устаревший RUNNING при локальной остановке и очистка защищённого runtime.

Неуспешные прогоны не объявлялись успешными: [первый](https://github.com/boyyhbm/Farm/actions/runs/41752838401), [путь движка](https://github.com/boyyhbm/Farm/actions/runs/41753334664), [сборка](https://github.com/boyyhbm/Farm/actions/runs/41753840294), [NSIS](https://github.com/boyyhbm/Farm/actions/runs/41754743612), [упаковка Dashboard](https://github.com/boyyhbm/Farm/actions/runs/41756253088), [ACL](https://github.com/boyyhbm/Farm/actions/runs/41757213133), [завершение с WSS](https://github.com/boyyhbm/Farm/actions/runs/41757655217).

Успешные диагностические прогоны [41758781176](https://github.com/boyyhbm/Farm/actions/runs/41758781176) и [41759039331](https://github.com/boyyhbm/Farm/actions/runs/41759039331) отдельно проверяли исправленные исходные файлы внутри поставляемого Windows-интерпретатора. Они не подменяют финальную проверку неизменённых EXE. Экспорт выпуска запрещает source overlay, неполный сценарий и пропущенный SCM-тест.

## Проверки для ваших компьютеров

**Не выполнены:** чистая Windows 11 без ранее установленных runtime, два физических дополнительных ПК, настоящая перезагрузка ОС, вход до пользовательского сеанса, диалоги UAC/SmartScreen, визуальное отсутствие консолей, физические GPU/температурные датчики, интерактивный Steam/CS2 и миграция между разными выпущенными версиями схемы. Установка той же версии поверх себя проверяет замену файлов и сохранность БД, не совместимость любой будущей миграции.

Для этих сценариев подготовлен [графический чек-лист без команд](WINDOWS-LOCAL-CHECKLIST-RU.md). SmartScreen не отключается. Канал подписанных автоматических обновлений ещё не опубликован. Windows frozen/PyInstaller-вариант и Authenticode-подпись не проверялись этим прогоном; поставлены проверенные embedded NSIS EXE.

Исторические Linux cross-build проверки сохранены [отдельно](windows-cross-build-history-2026-11-03.md). Ранее пройдены 8 реальных интеграционных проверок Supervisor → Python → SQLite → production Next в Linux; HTML-мастер и отображение ошибок проверены Chromium с явно тестовым IPC. Эти результаты не выдаются за Windows GUI-проверки.
