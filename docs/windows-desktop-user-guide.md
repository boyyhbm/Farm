# Windows: графический пользовательский процесс

Руководство описывает реализованный процесс оболочки. Фактические Windows CI-прогоны и границы проверки приведены в [отчёте](windows-desktop-verification.md). Установщики не подписаны. CI на Windows Server не заменяет приёмку на чистой Windows 11; отдельный [чек-лист](WINDOWS-LOCAL-CHECKLIST-RU.md) выполняется на ваших ПК.

## Главный компьютер

Откройте `CS2-Farm-Manager-Setup.exe`, выберите язык и каталог установки. Мастер создаёт ярлыки, запись в Windows Settings и деинсталлятор. После запуска программы мастер показывает проверку файлов поставки и системы, выбор режима, создание администратора, настройку компонентов, проверку соединения и переход к Dashboard. Используйте пароль не короче 14 символов. Программа хранит только его Argon2id-хеш; пароль не записывается в desktop.json.

В режиме главного компьютера создаётся SQLite БД и локальная очередь на диске пользователя. Backend и Dashboard слушают только loopback. Закрытие окна по умолчанию оставляет приложение в трее; «Выход» в меню или трее завершает компоненты. Параметры автозапуска и поведения закрытия доступны в System Management.

## Дополнительные ПК

В Settings → System Management откройте управление настольным приложением. В блоке подключения компьютеров выберите фактический сетевой интерфейс, проверьте адрес и явно подтвердите включение HTTPS. Программа генерирует собственный CA и серверный сертификат; приватные ключи зашифрованы, пароль ключей на Windows защищён DPAPI. Она не добавляет правила брандмауэра. При необходимости разрешите программу только для своей частной сети через Windows Security; не открывайте маршрутизатор в Интернет для этого сценария.

Скопируйте HTTPS-адрес и публичный CA по доверенному каналу. В Nodes создайте одноразовый код. Скачайте настоящий Agent Setup из панели, установите его на другом ПК и введите адрес, код и CA в мастер подключения. Для существующего сервера с общедоверенным сертификатом CA можно не указывать. Ошибка доверия или имени сертификата должна исправляться проверкой адреса/CA; отключения TLS-проверки нет.

В управлении агентом выберите Steam и CS2 через диалог файлов, если стандартная установка не найдена. Пустое поле означает недоступное приложение. Доступность появляется в Node Manager после фактического подключения и heartbeat. Steam/CS2 запускаются только из локального списка разрешений. Авторизуйтесь вручную в официальном Steam. Мастер предлагает фоновую службу Windows с подтверждением UAC: телеметрия работает независимо от окна и входа пользователя. Для Steam/CS2 нужен активный пользовательский сеанс. Можно выбрать и прежний интерактивный режим после входа. Управление службой, замена её файлов и повторная привязка доступны в System Management.

## Обслуживание

**Проверить соединение** показывает отдельные проверки файлов, каталога данных, Backend/очереди, Dashboard → API, целостности SQLite или TLS-соединения. Ошибка содержит код, причину и действия. Кнопка сохранения отчёта экспортирует JSON без секретов и содержимого БД. Heartbeat агента подтверждается отдельно в Nodes.

**Перезапуск компонентов** останавливает и запускает собственные процессы с ограниченным восстановлением. При ошибке откройте журнал в System Management. Зелёное состояние выводится только после healthcheck; чужой процесс на занятом локальном порту не принимается за Backend.

**Создать резервную копию** открывает диалог сохранения `.farmbackup`. Копируются основная БД и очередь с использованием SQLite backup API. Приватные TLS-ключи и Telegram-секреты не включаются. Архив содержит данные аккаунтов/финансов: храните его в защищённом месте.

**Восстановить** требует явного подтверждения и останавливает компоненты. Проверяются структура архива, целостность и ожидаемая схема; исходные данные сохраняются для отката. При ошибке замены выполняется откат. После успешного восстановления требуется заново войти в панель: прежние сессии авторизации отзываются. При переносе на другой компьютер настройте HTTPS и Telegram заново через GUI.

**Telegram** настраивается здесь же: токен, Chat ID и уровень важности. Секрет сохраняется через DPAPI, не возвращается в Dashboard и не передаётся в журналы. Пустой токен отключает уведомления.

**Обновления** принимаются только из канала, закреплённого издателем: проверяются HTTPS, Ed25519-подпись, хеш, версия и размер. Пока издатель не настроил канал, приложение прямо сообщает, что проверка недоступна. SmartScreen не обходится.

## Удаление

Откройте Windows Settings → Apps → Installed apps и выберите CS2 Farm Manager или CS2 Farm Agent. Интерактивный деинсталлятор отдельно спрашивает, нужно ли удалить локальные данные. Обычное сохранение данных позволяет переустановку; удаление с данными необратимо. Резервные копии вне каталога приложения сохраняются.

При удалении Agent, установленного как служба, Windows запросит UAC для её остановки и удаления. При отмене удаление приложения прерывается. Защищённая идентичность сохраняется для переустановки; для её явного удаления используйте «Отвязать и настроить заново» до деинсталляции.
